# Customer Churn Predictive Analytics

## Project Overview
This project focuses on identifying customers at risk of churning using predictive analytics. By analyzing historical customer data through a **CHAID (Chi-square Automatic Interaction Detection)** decision tree model in **IBM SPSS Modeler**, the objective is to generate a targeted list of high-risk individuals. This enables businesses to implement proactive retention strategies and effectively reduce customer attrition rates [cite: 3].

## Dataset Description
The project utilizes two primary datasets containing customer information to train and validate the predictive engine [cite: 1, 2].

### Files
* **`customer_churn_dataset-training-master.csv`**: The primary dataset used for model construction and training [cite: 1].
* **`customer_churn_dataset-testing-master.csv`**: The dataset used for model validation and performance evaluation [cite: 2].

### Key Features [cite: 1, 2]
The data includes the following key attributes:
* **Demographics**: Age, Gender.
* **Account Information**: Tenure, Subscription Type, Contract Length.
* **Usage Behavior**: Usage Frequency, Support Calls, Last Interaction.
* **Financials**: Total Spend, Payment Delay.
* **Target Variable**: **Churn** (Binary indicator of customer attrition).

## Methodology [cite: 3]
The analytical workflow follows a standard predictive modeling lifecycle:
1.  **Data Import**: Loading customer records into the analytical environment.
2.  **Preprocessing**: Cleaning and preparing variables for modeling.
3.  **Model Building**: Implementing the CHAID algorithm to identify churn patterns.
4.  **Analysis**: Identifying high-risk churn customers based on model output.

## Key Outcomes [cite: 3]
* **Strategic Insights**: Converts complex analytical findings into actionable business recommendations for data-backed retention.
* **Operational Efficiency**: Provides a refined list of customers with a high probability of churn for targeted intervention.
* **Learning Experience**: Demonstrates skills in constructing, validating, and analyzing decision tree models using IBM SPSS Modeler.

## Tools Used [cite: 3]
* **IBM SPSS Modeler**: Primary software for model development and analysis.
